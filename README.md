This project is a static academic website prototype for Paws Community Animal Shelter, a fictional non-profit animal-rescue organisation. It is designed to show how a small community organisation could present its purpose online and make key actions easy to find, including:
learning about the shelter and its work;
exploring adoption, foster-care, rehabilitation, volunteering and education services;
contacting the shelter;
submitting an adoption, foster, volunteer, donation or general enquiry; and
encouraging responsible pet ownership and community support.
The package is the Part 2 version of a web-development assignment. It builds on the Part 1 HTML prototype by adding a consistent visual design, responsive layouts, improved accessibility features and evidence of testing at desktop, tablet and mobile widths.
